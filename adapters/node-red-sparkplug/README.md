# Node-RED Sparkplug Plus

| | |
|---|---|
| **Language** | JavaScript (Node.js) |
| **Roles** | Edge + Decoding/Subscription |
| **Source** | [node-red-contrib-sparkplug-plus](https://flows.nodered.org/node/node-red-contrib-sparkplug-plus) |

Node-RED contribution nodes for Sparkplug B. Provides edge node simulation,
payload decoding, and topic subscription through the Node-RED visual flow
editor. Useful for testing Sparkplug B interoperability with low-code
integrations.

## Status

Planned — container image and harness adapter not yet implemented.
