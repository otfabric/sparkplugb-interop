# Eclipse Tahu Adapter

Eclipse Tahu is the reference implementation for Sparkplug B, maintained by the
Eclipse Foundation under EPL-2.0.

## Capabilities

| Capability | Supported |
|-----------|:---------:|
| Edge Node | ✓         |
| Host App  | ✓         |
| MQTT 3.1.1 | ✓       |
| MQTT 5.0  | ✓         |
| Aliases   | ✓         |
| Templates | ✓         |
| DataSets  | ✓         |

## Usage

The Tahu adapter provides a Java-based Sparkplug B edge node and host
application that can be used as independent reference implementations.

Container images will be published as:

```
ghcr.io/otfabric/sparkplugb-interop-tahu:dev
```
