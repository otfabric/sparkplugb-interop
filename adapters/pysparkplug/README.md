# PySparkplug

| | |
|---|---|
| **Language** | Python |
| **Roles** | Edge + Subscriber/Client |
| **Source** | [matteosox/pysparkplug](https://github.com/matteosox/pysparkplug) |

PySparkplug is a Python library for the Sparkplug B specification. It provides
Edge Node publishing, payload decoding, and MQTT subscription with typed metric
handling. Available on PyPI.

## Status

Planned — container image and harness adapter not yet implemented.
