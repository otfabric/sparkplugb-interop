# SparkplugNet

| | |
|---|---|
| **Language** | C# (.NET) |
| **Roles** | Edge + Host |
| **Source** | [SeppPenner/SparkplugNet](https://github.com/SeppPenner/SparkplugNet) |

SparkplugNet is a .NET library implementing the Eclipse Sparkplug B
specification. It provides both Edge Node and Host Application roles with full
lifecycle support, available as a NuGet package.

## Status

Planned — container image and harness adapter not yet implemented.
