# Nautilus

| | |
|---|---|
| **Language** | Go |
| **Roles** | Edge + Host |
| **Source** | [Nautilus](https://github.com/EvergenEnergy/nautilus) |

Nautilus is a Go library for Sparkplug B providing both Edge Node and Host
Application roles. It offers typed metric handling, lifecycle management, and
sequence validation.

## Status

Planned — container image and harness adapter not yet implemented.
