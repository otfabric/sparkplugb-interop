# srad

| | |
|---|---|
| **Language** | Rust |
| **Roles** | Edge + Application |
| **Source** | [srad](https://crates.io/crates/srad) |

srad is a Rust implementation of the Sparkplug B 3.0 specification. It provides
both Edge Node and Application roles with strongly-typed metrics, sequence
management, and birth/death lifecycle handling through idiomatic Rust APIs.

## Status

Planned — container image and harness adapter not yet implemented.
