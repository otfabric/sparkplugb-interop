# HiveMQtt.Sparkplug

| | |
|---|---|
| **Language** | C# (.NET) |
| **Roles** | Edge + Host |
| **Source** | [hivemq/hivemq-mqtt-client-dotnet](https://github.com/hivemq/hivemq-mqtt-client-dotnet) |

HiveMQ's official .NET MQTT client with Sparkplug B extension. Provides typed
metric handling, birth/death certificate management, and both Edge Node and Host
Application roles through the HiveMQtt.Sparkplug NuGet package.

## Status

Planned — container image and harness adapter not yet implemented.
